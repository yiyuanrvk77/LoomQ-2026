# 自定义量子 RISC-V 扩展指令规格（QUANT）

> 用途：满足 Bonus「自定义量子 RISC-V 扩展指令」的①指令编码规格文档。
> 对应实现：`starter_kit/riscv_emulator.py`（已增加 `quant` 指令）。

## 1. 设计目标

在 L3 的经典控制流（RISC-V 子集）之上，增加一条量子门指令，让混合程序里的经典部分
能够"发起一次量子门操作"。为保持模拟器轻量，采用 4 状态约定在整数寄存器上表示单比特态。

## 2. 汇编格式

```text
quant rd, imm
```

- `rd`：目标寄存器（作为单比特的索引，`x0..x31`）。
- `imm`：门编码，取值 `0 / 1 / 2`。

## 3. 门编码

| imm | 门 | 作用 |
|---|---|---|
| 0 | H（Hadamard） | |0⟩↔|+⟩、|1⟩↔|−⟩ |
| 1 | X（NOT） | |0⟩↔|1⟩、|+⟩↔|−⟩ |
| 2 | Z（相位翻转） | |+⟩↔|−⟩，|0⟩/|1⟩ 不变 |

## 4. 状态约定

| 整数值 | 量子态 |
|---|---|
| 0 | |0⟩ |
| 1 | |1⟩ |
| 2 | |+⟩ |
| 3 | |−⟩ |

该约定是 H / X / Z 三个单比特门在计算基与 X 基下的最小自洽闭包（4 个状态即可表达）。

## 5. 二进制编码规格（R 型）

采用**开源 RISC-V 指令集架构**预留的自定义扩展空间 custom-0 opcode
（`0001011`，见 RISC-V Unprivileged ISA 规范的 custom 指令编码区），使 QUANT 扩展
闭环到开源、可自由实现的指令集，而非私有编码：

| 位段 | 含义 | 取值 |
|---|---|---|
| `[31:25]` funct7 | 标记为量子扩展 | `0000001` |
| `[24:20]` rs2 | 门编码 imm | `0 / 1 / 2` |
| `[19:15]` rs1 | 未使用 | `00000` |
| `[14:12]` funct3 | 类型 | `000` |
| `[11:7]` rd | 目标寄存器 | `0..31` |
| `[6:0]` opcode | custom-0 | `0001011` |

即 `funct7=0000001, rs2=imm, rs1=0, funct3=000, rd=目标, opcode=0001011`。

## 6. 实现与测试

- 实现位置：`starter_kit/riscv_emulator.py`（保留全部官方 L3 指令不变）。
- **编码环节**：`encode_quant(rd, imm) -> int` 按第 5 节的 R 型布局，把 `quant rd, imm`
  汇编编码成 32 位机器码；`load_program()` 解析到 `quant` 时立即编码，存入执行队列的
  是机器码而非文本助记符。
- **解码环节**：`decode_quant(word) -> (rd, imm)` 校验 `opcode==0001011` 且
  `funct7==0000001` 后，从机器码提取 `rd` 与 `imm`；`execute()` 执行 `quant` 时先解码再
  按门编码更新寄存器。
- 即自定义指令的二进制编码真正进入「汇编 → 编码 → 机器码 → 解码 → 执行」的可运行闭环，
  而非仅存在于本文档。
- 端到端测试命令：

```bash
python3 starter_kit/examples/riscv_extension_demo.py
```
