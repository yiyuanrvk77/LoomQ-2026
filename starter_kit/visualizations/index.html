Levels

三层，从「能用」到「硬核」

每一层都写清三件事：做了什么、怎么体验、现在到什么程度。

L1

统一中间层 Transpiler

做了什么

把同一条量子电路翻译成三个平台的「方言」，让它在量旋、本源、AWS Braket 上都能运行；缺对应 SDK 时自动回退到内置无噪声模拟器。只处理 12 个标准门，并统一位序为 little-endian。

怎么体验

python3 starter_kit/evaluator.py --level l1 --target spinq,originq,braket

也可以看 examples/ 里的 run_spinq / run_originq / run_braket。

现状 / 证据

真机证据统一放 starter_kit/evidence/：量旋云真机（gemini_vp，2 比特）已跑通 Bell 态，job G-260816-0001 · shots 1024。run() 只负责本地模拟器的转译与执行，真机不在它里面实现。

L2

说人话的 Agent

做了什么

你说一句话，它生成或修复 OpenQASM 电路，并帮你挑后端；生成后先用 L1 自己跑一遍「自验」，不对就重试，直到能运行。

怎么体验

python3 starter_kit/web_demo.py   # 浏览器打开 127.0.0.1:8000
python3 starter_kit/loomq_cli.py  # 命令行入口

需要先配置模型 Key（LOOMQ_LLM_*）。

现状 / 证据

网页可完成 3 个零基础任务：生成 3 比特 GHZ、按约束选后端、修复报错电路；缺 Key 时会给出清晰的中文提示。

L3

Hybrid-QASM × RISC-V

做了什么

输入「量子 + 经典控制」的混合程序，编译器把它拆成「纯量子操作序列」和「RISC-V 汇编」两部分；手写词法分析 + 递归下降解析，真正通用编译，不是查表。

怎么体验

python3 starter_kit/evaluator.py --level l3

另有量子 RISC-V 扩展指令 quant（Bonus）。

现状 / 证据

Hybrid-QASM 解析与编译已实现；量子 RISC-V 扩展可跑 examples/riscv_extension_demo.py。
